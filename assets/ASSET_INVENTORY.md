## Usage Recommendations for Vertex Design System

### Section Backgrounds
- **Hero sections:** Cosmic wallpapers (dark, dramatic, premium)
- **Features sections:** Cinematic wallpapers (engaging, storytelling)
- **Stats sections:** Abstract wallpapers (clean, data-friendly)
- **CTA sections:** Nature wallpapers (calming, trustworthy)

### Glass Overlay Compatibility
- Dark wallpapers (cosmic, cinematic) work best with frosted glass overlays
- Light/bright wallpapers (nature, abstract) need darker glass or tinted overlays
- Wallpapers with high contrast work best for readability

### Responsive Strategy
- Desktop wallpapers (16:9) for desktop/tablet layouts
- Mobile wallpapers (9:16) for mobile layouts
- Use `object-fit: cover` with `object-position: center` for responsive cropping

### Asset Optimization
- Compress to WebP for ~50-70% size reduction
- Generate 3 sizes: original, 50% (for thumbnails), 25% (for previews)
- Create blurred placeholder versions for lazy loading
- Estimated total after optimization: ~15-25MB
