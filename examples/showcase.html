What are Material Themes?

Material themes are complete surface treatments that derive every color, texture, and accent from a single industrial process. Each theme defines surface elevation, text hierarchy, border systems, accent colors, and a unique background texture. Choose one material per page and derive everything from it.

Machining
Default material. CNC precision. Blue accent. 8px plotting grid texture. Best for dev tools, AI/ML, and infrastructure platforms.
Plating
PCB routing aesthetic. Teal accent. Trace-line texture. Best for data platforms, APIs, and integration tools.
Welding
Steel frame assembly. Amber accent. Structural grid texture. Best for open-source tools, platforms, and frameworks.
Casting
Foundry / forge. Red accent. Hazard hatching texture. Best for hardware, robotics, manufacturing, and energy.
Calibrating
Mission control. Amber accent. Instrument grid texture. Best for monitoring, trading terminals, and real-time ops.
Printing
Light mode docs. Blue accent. Hairline rules texture. Best for documentation, research, legal, and finance.

Layout Modes

Four layout modes for different content types. Each mode defines how content relates to the viewport edge and how the grid behaves.

BOXED (Default) — .chassis

Centered max-width chassis with visible page-ground gutters. Best for most pages, dashboards, and docs.

max-width: 1280px; margin: 0 auto; border-left: 1px solid var(--line-2); border-right: 1px solid var(--line-2);
FULL-BLEED — .full-bleed-section

Content reaches every edge of the viewport. Best for infrastructure platforms and full dashboards.

width: 100%; padding: var(--geist-gap-double) clamp(24px, 5vw, 96px);
SPLIT — .split-section

Message column + live-evidence column. Best for API products, SDKs, and AI demos.
