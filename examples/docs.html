System Overview

Vertex is a precision-engineered design system that merges Vercel's Geist design language with industrial frontend architecture. It treats every interface as a machine: engineered, not decorated.

The system is built on three pillars: real Geist tokens extracted from vercel.com/geist, industrial design patterns from the manufacturing world, and frosted glass overlays for depth and premium feel.

Color Tokens

The color system uses real Geist tokens with a three-tier structure: Neutral (80%), Accent (10%), and Semantic (5%).

Tier Usage Examples
Neutral Backgrounds, text, borders --ds-gray-100 to --ds-gray-1000
Accent Primary actions, key data --ds-blue-700 (#0072f5)
Semantic Status indicators --ds-green-700, --ds-red-700

Glass System

Frosted glass is an optional overlay layer, not a base material. It adds depth without obscuring the grid beneath.

/* Glass tokens */
--glass-bg: rgba(255, 255, 255, 0.03);
--glass-border: rgba(255, 255, 255, 0.06);
--glass-blur: blur(16px) saturate(180%);

/* Apply to navbar, modals, floating cards */
.glass {
  background: var(--glass-bg);
  backdrop-filter: var(--glass-blur);
  border: 1px solid var(--glass-border);
}

Layout Modes

Four layout modes define the chassis shape: BOXED (default), FULL-BLEED, SPLIT, and DOCUMENT.

BOXED — Centered max-width chassis with visible gutters. Best for dashboards, docs, B2B premium.

FULL-BLEED — Edge-to-edge content. Best for infrastructure platforms, full dashboards.

SPLIT — Message column + live-evidence column. Best for API products, AI demos.

DOCUMENT — Print-grid with wide margins. Best for research, documentation.
